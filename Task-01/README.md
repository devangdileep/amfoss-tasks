# Commands I Learned While Doing This Task

This document contains the commands I learned while completing each level of the task.

---

## Master

`touch README.md` : Creates a new file in the current directory.

`git add README.md` : Adds modified or newly created files to the Git staging area.

`git commit -m "commit message"` : Commits the changes present in the staging area with a descriptive message.

`git push` : Pushes the committed changes from the local repository to the remote GitHub repository.

## Commit one file
